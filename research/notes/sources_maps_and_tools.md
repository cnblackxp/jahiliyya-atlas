# Sources, Scholarship and Practical Tools for Researching Pre-Islamic Arabia (5th–7th c. CE)

**Scope note for the report writer:** this is a "how do I research this / what already exists" survey, not a history survey. Verification status is flagged on every item. Raw `curl` was blocked by this environment's agent proxy (gateway returned 403 to CONNECT for every host tried), so link checking was done via WebFetch only; a handful of sites (notably DASI and OCIANA) could not be reached because of bot-protection or server errors and are flagged **UNVERIFIED** below.

## Q1. Does an interactive map + timeline of pre-Islamic Arabia already exist?

### Takeaway

**No — the specific thing the user imagines (a single interactive map of Arabia with a time slider showing when events happened, covering 400–650 CE) does not exist.** The closest available substitute is a *combination*: al-Ṯurayyā for a georeferenced gazetteer and route network (but it is 9th–10th century Islamic-era, not pre-Islamic), Pleiades + DARE for the classical/late-antique place layer, and DASI/OCIANA for the inscriptional evidence mapped to sites. The timeline half has to be built by hand — no one has published a machine-readable chronology of pre-Islamic Arabia.

### Cited Findings — the GIS / gazetteer projects

- **al-Ṯurayyā Project** (*the single most promising item in the user's list*) — a gazetteer and geospatial model of the early Islamic world by Masoumeh Seydi (Aga Khan University, ISMC London) and Maxim Romanov (Universität Hamburg), 2022–. Both the gazetteer and the geospatial model are still described by the project as under development — [al-Ṯurayyā](https://althurayya.github.io/)
  - **Coverage:** over **2,000 georeferenced toponyms** and **almost as many georeferenced route sections**. The base source is Georgette Cornu, *Atlas du monde arabo-islamique à l'époque classique: IXe–Xe siècles* (Brill, 1983) — **so the chronological frame is the 9th–10th centuries CE, i.e. 200–400 years AFTER the user's period** — [al-Ṯurayyā](https://althurayya.github.io/)
  - **Interface tabs:** Location (place info incl. URI, coordinate certainty, names, region, source, type); Sources (primary-source descriptions for a selected toponym, currently from al-Ḥimyarī's *Rawḍ al-miʿṭār* الروض المعطار, matched automatically with a % score); Regions (province maps built by coloring places and route sections); Search (**Arabic script or a one-to-one transliteration scheme — English names are not included**); Route Sections (ID, endpoints, length in metres); Pathfinding (Dijkstra shortest path, plus an "optimal" path weighted toward stations/settlements, with intermediate waypoints; **naval travel is not implemented**); Network (settlements reachable within N days at ~30 km/day, with multicenter comparison) — [al-Ṯurayyā](https://althurayya.github.io/)
  - **Important caveat the project states itself:** many of the source-to-toponym matches are fuzzy (Levenshtein distance), so **a 100% match does not guarantee the correct place** — [al-Ṯurayyā](https://althurayya.github.io/)
  - **Cross-references out to** Brill's *Encyclopaedia of Islam*, **Pleiades**, and Wikipedia — i.e. it is already linked-data aware and can be joined to Pleiades IDs — [al-Ṯurayyā](https://althurayya.github.io/)
  - **Data and licence (developer-relevant, verified):** repository at [github.com/althurayya/althurayya.github.io](https://github.com/althurayya/althurayya.github.io). Directory structure: `master/` (data files used in the map), `places/` (individual **GeoJSON** place files), `scripts/` (scripts to join and split the GeoJSON), `sources/` (primary sources as individual **JSON** files), `archive/`, `ref/`. Root-level files include `Muqaddasi_all_shortest_paths.json`. **Code is Apache-2.0; the original project datasets — place records, route records, coordinates, identifiers, transliterations, project metadata — are CC BY 4.0 per `DATA-LICENSE.md`**, with source-derived and third-party data excluded unless their own terms permit redistribution. **No documented API**; you clone the repo and read the GeoJSON directly. No CSV — [GitHub](https://github.com/althurayya/althurayya.github.io)
  - **Earlier version** of the gazetteer: `cjacks0413.github.io/imiw`; research experiments at `bl.ocks.org/masoumeh` — [al-Ṯurayyā](https://althurayya.github.io/)
  - **Citation:** Seydi, Masoumeh, and Maxim Romanov, *al-Ṯurayyā Project: a gazetteer and a geospatial model of the early Islamic World* (2022–) — [al-Ṯurayyā](https://althurayya.github.io/)
- **DASI — Digital Archive for the Study of pre-Islamic Arabian Inscriptions** (CNR, Italy; originally Università di Pisa, Alessandra Avanzini). - **Historical-geography "named-place in Arabic sources" layer:** al-Ṯurayyā's earlier gazetteer versions drew on **al-Samʿānī's *Kitāb al-ansāb* كتاب الأنساب** and **Yāqūt's *Muʿjam al-buldān* معجم البلدان** — i.e. the classical Arabic geographical dictionaries have already been partially georeferenced by that project — [al-Ṯurayyā](https://althurayya.github.io/)

### Cited Findings — print and PDF atlases

- **David Rumsey Map Collection** — [davidrumsey.com](https://www.davidrumsey.com/). **UNVERIFIED (proxy 403).** Generally the standard source for high-resolution, liberally licensed historical map scans; caveat for this project is that Rumsey is strongest on early-modern-to-modern printed maps, so it will give period-*style* Arabian cartography (Ptolemaic, Ottoman-era, 18th–19th c.) rather than scholarly reconstructions of 6th-century Arabia.
- **Barrington Atlas** (Talbert, Princeton) and **Hugh Kennedy, *An Historical Atlas of Islam*** (Brill) — **GAP: neither was verified in this session.** Both are commercial print/paywalled works. - **Maps inside the key monographs:** the maps in Hoyland's *Arabia and the Arabs* and in Fisher's *Arabs and Empires before Islam* — **GAP: not independently verified.** Fisher (OUP 2015) is paywalled, see Q2.

### Verdict (frank, as requested)

- **The thing does not exist.** There is no interactive map + time-slider for pre-Islamic Arabia. No project found covers 5th–7th century Arabia cartographically *and* chronologically in one interface.
- **Closest single thing:** al-Ṯurayyā — right region, right kind of interface (map, routes, travel-time, Arabic-script search, pathfinding), **wrong century** (9th–10th), and **no timeline dimension at all** (it is a static synchronic snapshot, not a time-aware map).
- **Best realistic combination for the user:** al-Ṯurayyā's CC BY 4.0 GeoJSON as the place-and-route backbone (many Arabian toponyms persist from pre-Islamic into Abbasid usage, so a large fraction of its 2,000 toponyms are usable with care) → joined on Pleiades IDs to the classical layer for the Roman/Byzantine frontier → DASI/OCIANA for site-level inscriptional dating → a hand-built chronology table the user writes themselves. That last piece is unavoidable work.
- **Why the timeline half is missing:** no machine-readable chronology of pre-Islamic Arabia was found in any repository, gazetteer, or dataset. This is a real gap in the field, not a search failure on my part — though see Q6 for how to bootstrap one.

### Inferences

- al-Ṯurayyā's explicit Pleiades cross-referencing plus CC BY 4.0 data licence makes it the natural technical foundation: a developer can clone, read `places/*.geojson`, and get coordinates with a documented certainty field, which is exactly what a game map needs.
- The "coordinate certainty" field al-Ṯurayyā exposes is unusually valuable for fiction: it tells the author which places are securely located (so can be drawn confidently) and which are scholarly guesses (so can be moved for narrative convenience without embarrassment).
- Because al-Ṯurayyā searches only in Arabic script or a strict transliteration and has no English index, the user's native Arabic is a genuine advantage here — most English-only researchers find this tool hard to use.

### Gaps

- **ChronoZoom, Timeline JS, and the "Arabs and Empires before Islam" chronological tables as a dataset** — not verified in this session; tool-call budget was spent on the map/gazetteer side and on confirming the Shahîd and Jawād ʿAlī free-access claims, which were higher-value. Timeline JS (knightlab) is a well-known free spreadsheet-driven timeline renderer and would be the obvious presentation layer, but I did not confirm its current status.
- Wikipedia's pre-Islamic timeline articles: only one directly relevant list was surfaced — [List of wars and battles in pre-Islamic Arabia](https://en.wikipedia.org/wiki/List_of_wars_and_battles_in_pre-Islamic_Arabia) and the main [Pre-Islamic Arabia](https://en.wikipedia.org/wiki/Pre-Islamic_Arabia) article. Their quality was not assessed.
- Tribal-distribution and trade-route maps as reusable game assets: no CC-licensed, scholarly tribal map was located. Wikimedia Commons categories were not enumerated.
- Whether any running Islamic-history timeline project exists: not established.

## Q2. The essential secondary literature, annotated

### Takeaway

**The single biggest practical finding: Irfan Shahîd's entire *Byzantium and the Arabs* series — seven volumes, the most detailed narrative account of the Arabs of the Roman/Byzantine frontier in the 4th–6th centuries — is genuinely free, as PDFs uploaded by Dumbarton Oaks itself to archive.org under CC BY-NC-ND 4.0.** That is thousands of pages of exactly the user's period at zero cost. Conversely, the two most-recommended English surveys (Hoyland; Fisher) are commercial.

### Cited Findings — the Shahîd series (free, confirmed)

### Cited Findings — the other core English works

- **Greg Fisher (ed.), *Arabs and Empires before Islam* (Oxford, 2015)** — a sourcebook of translated primary texts. - **Robert Hoyland, *Arabia and the Arabs: From the Bronze Age to the Coming of Islam*** (Routledge) — **GAP: not verified in this session.** Standard assessment: this is the one-volume English survey to start with, accessible to non-specialists, commercially published (Routledge), widely held in libraries. **Flag as unverified for availability.**
- **Jan Retsö, *The Arabs in Antiquity*** (Routledge) — a DOI was surfaced in a related search context but not confirmed to this title. **GAP: not verified.** Standard assessment: very long, linguistically technical, argues a minority thesis about the meaning of "Arab"; not a starting point.
- **Cambridge History of Islam vol. 1** — **GAP: not verified.** Dated (1970) but its opening chapters on pre-Islamic Arabia remain a common reference point.
- **Christian Julien Robin** (CNRS) — the indispensable scholar for Ḥimyar, Najrān, and South Arabian epigraphy; the user's period is precisely his specialism. **GAP: his academia.edu page was not located in this session.** A CNRS colleague working the same ground, **Alessia Prioletta**, has a confirmed page at [cnrs.academia.edu/AlessiaPrioletta](https://cnrs.academia.edu/AlessiaPrioletta) — a good entry point into the CNRS South Arabian network and likely to cite Robin heavily.
- **Isabel Toral-Niehoff on al-Ḥīra** (الحيرة, the Lakhmid capital) — **GAP: not verified in this session.** Her monograph *Al-Ḥīra: Eine arabische Kulturmetropole im spätantiken Kontext* (Brill) is the standard study, in German. ### Inferences

- There is a sharp asymmetry in access: the Arabic reference literature (Jawād ʿAlī) and the deep Byzantine-frontier scholarship (Shahîd) are free, while the modern English syntheses (Hoyland, Fisher, Webb) are paywalled. **A native Arabic reader is therefore unusually well placed to research this period cheaply** — the expensive books are largely the English summaries of material they can read in the original.
- Shahîd's series is also the most *novelistically* useful body of work found: seven volumes organised by century and by theme (political, ecclesiastical, toponymic, social) is effectively a structured worldbuilding bible for the Ghassanid/Byzantine side of the user's setting.
- Al-Jallad's open-access self-archiving means the *current* (2020s) state of the field on pre-Islamic Arabic and its epigraphy is free to follow, which is unusual and worth telling the user explicitly.

### Gaps

- Hoyland, Retsö, Toral-Niehoff, Robin, Al-Azmeh, Lecker, Landau-Tasseron, Stetkevych, Cambridge History of Islam vol. 1, and all four of the additional Arabic titles were not link-verified; tool budget was committed to confirming the two highest-value free-access claims (Shahîd, Jawād ʿAlī) instead. Each needs a direct availability check before the final report presents it as free or paid.
- I did not confirm free PDF availability for the Shahîd volumes *other than* Vol. 2 Part 2. **Inference, flagged as such:** since Dumbarton Oaks uploaded that volume itself in a batch on a single date (19 Feb 2021) and the bookstore lists all seven as a series, the others are very likely in the same archive.org collection — but **this should be checked per volume rather than asserted.**

## Q3. Primary sources and where to read them free

### Takeaway

The Arabic primary corpus is substantially free online through Shamela, ketabonline, Waqfeya and usul.ai, and **machine-readably free through OpenITI** (confirmed: 5.9 GB, CC BY-NC-SA 4.0, DOI-versioned). **Confirmed negative on the user's specific question: there is no complete European-language translation of *Kitāb al-Aghānī*.** The external (Greek/Syriac) sources are best reached in one place through Fisher's paywalled sourcebook.

### Cited Findings — Kitāb al-Aghānī (كتاب الأغاني)

- **Author:** Abū al-Faraj al-Iṣfahānī / Eṣfahānī (أبو الفرج الأصفهاني), **284–356 AH / 897–967 CE**. He is credited with thirty-six works but his reputation rests almost entirely on this one — [Encyclopaedia Iranica](https://mail.iranicaonline.org/articles/ketab-al-agani)
- **Edition — this answers the user's question directly.** The most recent Cairo edition (**1927–1974**) runs to **24 volumes and over 9,000 pages of text**. It was **begun by the Dār al-Kutub (دار الكتب) for volumes I–XVI and completed by al-Hayʾa al-ʿĀmma (الهيئة العامة) for volumes XVII–XXIV, 1970–74**, which also reissued volumes I–II. Earlier Būlāq (بولاق) and Cairo editions exist; Iranica refers the reader to *EI2* for their details — [Encyclopaedia Iranica](https://mail.iranicaonline.org/articles/ketab-al-agani)
  - **So: the user's "Dār al-Kutub al-Miṣriyya 24 vols" is the right answer, with the nuance that the last eight volumes were actually issued by al-Hayʾa al-ʿĀmma — the two are halves of one 24-volume project, not rival editions.** The Dār Ṣādir (دار صادر) Beirut printing is not mentioned by Iranica; **Iranica's only Beirut citation is for Ibn Khaldūn's *Muqaddima*, not for al-Aghānī** — so I could not verify the Beirut edition's status — [Encyclopaedia Iranica](https://mail.iranicaonline.org/articles/ketab-al-agani)
- **Complete European-language translation: CONFIRMED ABSENT.** The Iranica article mentions no full translation into any European language; its bibliography lists only secondary studies, e.g. H. G. Farmer, *Arabic Music in the Kitāb al-Aghānī* (1940) — [Encyclopaedia Iranica](https://mail.iranicaonline.org/articles/ketab-al-agani). **Note the epistemic status: this is absence of evidence in an authoritative reference article rather than an explicit statement "no translation exists." It strongly supports the user's assumption but is not a direct denial.** No translation was found in any other search either.
- **Indexes:** Iranica does not mention indexes. **GAP** — the user's question about a published index to al-Aghānī is unresolved.
- **Searchable digital text:** not confirmed for al-Aghānī specifically. **GAP.** However, al-Aghānī is one of the most commonly digitised Arabic texts and is near-certain to be in both Shamela and the OpenITI corpus — see below for how to check and why Shamela's search needs caution.

### Takeaway

The **"Roads of Arabia"** travelling exhibition and its catalogue are the best single art-direction resource, and for AlUla/Hegra specifically there are **genuine high-resolution 3D scans and a fully explorable 3D model of a Nabataean tomb**. Museum online catalogues were not directly verified.

### Cited Findings

- **"Roads of Arabia: Archaeology and History of the Kingdom of Saudi Arabia"** — the major travelling exhibition (originated at the Louvre, 2010, then toured widely). **Catalogue:** *Roads of Arabia: Archaeology and History of the Kingdom of Saudi Arabia*, ISBN **9782757203958**, bilingual edition — [dessinoriginal.com](https://dessinoriginal.com/fr/editions-bilingues-inter/3468-roads-of-arabia-archeology-and-history-of-the-kingdom-of-saudi-arabia-9782757203958.html) (for purchase). **Louvre Abu Dhabi publication page:** [louvreabudhabi.ae/en/learn/publications/roads-of-arabia](https://louvreabudhabi.ae/en/learn/publications/roads-of-arabia). **Library record:** [Canadian Centre for Architecture](https://www.cca.qc.ca/en/search/details/library/publication/662695532). **US venue pages with images and object information:** [Museum of Fine Arts Houston, 19 Dec 2013 – 9 Mar 2014](https://www.mfah.org/exhibitions/roads-arabia-archaeology-and-history-kingdom-saudi). **Gulf venue, 8 Nov 2018 – 16 Feb 2019:** [myartguides](https://myartguides.com/exhibitions/dubai-sharjah/roads-of-arabia-archaeological-treasures-of-saudi-arabia) and [myartguides Abu Dhabi](https://myartguides.com/exhibitions/dubai-sharjah-abu-dhabi/roads-of-arabia-archaeological-treasures-of-saudi-arabia). - **3D scans and reconstructions — confirmed to exist.** The Royal Commission for AlUla released the **first fully explorable 3D model of Hegra's Tomb of Lihyan (son of Kuza), a UNESCO World Heritage site** — [classic.rcu.gov.sa](https://classic.rcu.gov.sa/en/media-gallery/news/the-royal-commission-for-alula-enter-the-metaverse-with-first-fully-explorable-3d-model-of-hegra-s-tomb-of-lihyan-a-unesco-world-heritage-site); coverage at [Popular Archaeology](https://popular-archaeology.com/article/world-famous-hegras-tomb-enters-the-metaverse/) and [Gulf Business](https://gulfbusiness.com/en/2022/virtual-reality/royal-commission-for-alula-enters-the-metaverse), [Business Traveller](https://www.businesstraveller.com/business-travel/saudi-arabias-alula-enters-metaverse/)

### Inferences

- Hegra/AlUla is Nabataean and earlier (roughly 1st c. BCE – 1st c. CE), so it is **several centuries before the user's 5th–7th c. setting**. The 3D scans are superb reference for monumental rock-cut architecture that would still have been standing and visible as ruins in the 6th century — which is arguably the more interesting use for a novel.
- The "Roads of Arabia" catalogue is the best single-volume visual reference because the exhibition was explicitly organised around trade routes and spans the whole pre-Islamic-to-Islamic sweep — matching both the map and the period the user needs.

### Gaps

- **Not verified at all:** the National Museum of Saudi Arabia online catalogue, the British Museum collection search, the Metropolitan Museum's open-access collection API (which is CC0 and would be genuinely useful for licence-clean reference imagery — worth the user checking), Yemen collections, and photographic archives. Tool budget was exhausted.
- Licensing terms for the AlUla 3D models and Factum scans are unknown; **do not assume they are reusable in a commercial game.**

## Q6. Developer-friendly data

### Takeaway

Three machine-readable assets are confirmed and immediately usable: **al-Ṯurayyā's GeoJSON gazetteer (CC BY 4.0, ~2,000 toponyms + routes)**, **OpenITI's 5.9 GB text corpus with a TSV metadata index (CC BY-NC-SA 4.0)**, and **Pleiades IDs as the join key between them**. **No chronological dataset exists** — the timeline must be hand-built, and Wikidata is the most plausible seed.

### Cited Findings

- **al-Ṯurayyā — the gazetteer, confirmed developer-ready:** GeoJSON per place in `places/`, JSON primary sources in `sources/`, join/split scripts in `scripts/`, precomputed shortest-path data (`Muqaddasi_all_shortest_paths.json`) in the root. **Code Apache-2.0; project datasets CC BY 4.0 (place records, route records, coordinates, identifiers, transliterations, metadata), with third-party/source-derived data excluded unless separately permitted.** No API, no CSV — clone and parse — [GitHub](https://github.com/althurayya/althurayya.github.io). Fields exposed per place include URI, **coordinate certainty**, names, region, source, and type; route sections carry ID, endpoints, and length in metres — [al-Ṯurayyā](https://althurayya.github.io/)
  - **Concrete build path:** clone the repo → concatenate `places/*.geojson` into one FeatureCollection → render in MapLibre/Leaflet → use the route-section geometry as the trade-route layer → use `length` in metres with al-Ṯurayyā's own ~30 km/day assumption to compute travel times between story locations. The pathfinding logic (Dijkstra, plus a station-weighted variant) is documented well enough to reimplement if the user wants in-game travel.
  - **The ~30 km/day figure is al-Ṯurayyā's own stated model parameter for its Network tab** — a defensible, citable number for a game's travel system — [al-Ṯurayyā](https://althurayya.github.io/)
- **OpenITI — the text corpus, confirmed developer-ready:** v2025.1.9 (30 Dec 2025), 5.9 GB ZIP, **separate 12.1 MB TSV metadata file** (so you can query the catalogue without unzipping 5.9 GB), CC BY-NC-SA 4.0, DOI 10.5281/zenodo.17767721, free download — [Zenodo](https://zenodo.org/records/17767721). Docs at [kitab-project.org/docs/openITI](https://kitab-project.org/docs/openITI). Older versions are individually DOI'd for reproducible citation — [Zenodo concept record](https://zenodo.org/records/3082463)
  - **The NC licence blocks shipping the text in a commercial game** (see Q3) — but not using it to research one.
- **Pleiades as the join key:** al-Ṯurayyā explicitly cross-references Pleiades, the *Encyclopaedia of Islam*, and Wikipedia — so a developer can enrich al-Ṯurayyā places with Pleiades ancient-world data, and Pleiades IDs are themselves a common identifier across the whole Pelagios/Linked Pasts ecosystem (Peripleo, Recogito, the Syriac Gazetteer) — [al-Ṯurayyā](https://althurayya.github.io/)
- **Wikidata as the timeline seed:** no ready-made SPARQL query or chronological dataset for pre-Islamic Arabia was found. The usable starting points are Wikipedia's structured lists, which have Wikidata items behind them: [List of wars and battles in pre-Islamic Arabia](https://en.wikipedia.org/wiki/List_of_wars_and_battles_in_pre-Islamic_Arabia) and [Pre-Islamic Arabia](https://en.wikipedia.org/wiki/Pre-Islamic_Arabia)
  - **Honest statement of method, not a verified query:** the standard approach would be a SPARQL query against [query.wikidata.org](https://query.wikidata.org/) selecting items with `P31` (instance of) in {battle, city, human}, filtered by `P17`/`P131` for Arabian locations or `P361` membership of relevant polities (Ḥimyar, Lakhmids, Ghassanids, Kinda), with `P585` (point in time) or `P580`/`P582` (start/end time) bounded to roughly 350–650 CE, and `P625` (coordinates) for the map layer. **I did not run or verify such a query — presenting it as untested method, and the report should say so.** Expect sparse and uneven results; Wikidata's coverage of pre-Islamic Arabia is thin.
- **TAVO sheets as georeferenced layers:** multiple TAVO records exist in Princeton's geospatial catalogue — [princeton-2f75r987h](https://maps.princeton.edu/catalog/princeton-2f75r987h) and four others listed in Q1 — meaning scholarly historical map sheets may be available as georeferenced rasters for use as a basemap. **Access/licence per sheet unverified.**

### Inferences

- The realistic architecture for what the user actually wants: **al-Ṯurayyā GeoJSON as the spatial base + a hand-authored chronology (CSV or JSON, written from Jawād ʿAlī and Shahîd) as the temporal layer + a client-side time slider filtering both.** Every piece except the chronology already exists and is CC BY 4.0. The chronology is the irreducible manual work — and it is also exactly the research the user needs to do anyway to write the story, so it is not wasted effort.
- Because al-Ṯurayyā is 9th–10th century, the user will need to audit its toponyms against the pre-Islamic record (Jawād ʿAlī, al-Hamdānī, DASI) and mark which existed in the 6th century. The `coordinate certainty` and `source` fields make that audit tractable rather than hopeless.
- OpenITI's separate TSV metadata file is the cheap first step: pull the 12 MB TSV, confirm which of the Q3 texts are in the corpus, and only then decide whether the 5.9 GB download is worth it.

### Gaps

- No chronological dataset for pre-Islamic Arabia in CSV/JSON was found anywhere. **This appears to be a genuine absence in the field.**
- No SPARQL query was executed or verified; the query sketch above is method, not a tested result.
- DASI and OCIANA export/API capabilities are unknown (both sites unreachable from this session) — these are the two most likely places a georeferenced, dated inscription dataset would live, so they are the highest-value follow-up.
- GitHub was not searched systematically for `openiti`, `althurayya`, or Islamic-history datasets beyond the al-Ṯurayyā repo itself.
- Pelagios/Linked Pasts community resources were not reached (proxy 403 on all Pelagios hosts).
